# Rajput Book Store

A responsive front-end online bookstore built with HTML, CSS and vanilla JavaScript.

## Features
- Home page with featured books
- Product/book collection
- Search and category filter
- Book detail pages
- Shopping cart using localStorage
- Cart item counter
- Demo account form
- Responsive design for mobile and desktop
- No backend required

## Run locally
Open `index.html` in a browser.

## Deploy
This is a static website and can be deployed directly to GitHub Pages, Vercel or Netlify.
